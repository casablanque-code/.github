# Security Policy

## Поддерживаемые версии

Поддерживается только последняя мажорная версия каждого проекта, если не указано иное
в README конкретного репозитория.

## Сообщить об уязвимости

Пожалуйста, не создавайте публичный Issue для уязвимостей безопасности.
Вместо этого используйте вкладку **Security → Report a vulnerability** (GitHub Private
Vulnerability Reporting) в соответствующем репозитории, либо напишите напрямую [укажи email/контакт].

Постараюсь ответить в течение 7 дней.
